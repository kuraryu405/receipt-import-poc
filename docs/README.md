## 記録の方針

- 実APIの計測と、APIを模擬した実装確認は区別します。
- 精度指標には対象件数・分母・正規化・除外条件を添えます。
- 単発の処理時間を平均値や性能保証として扱いません。
- APIキー、画像、画像URL、店舗名や購買明細などの参照値・予測値は保存しません。添付するJSONは集計値だけにします。
- 新しい計測は日付別に追加し、過去の結果を上書きしません。実行時のコミット、モデル、対象範囲、APIの成功・失敗件数、計測条件を記録します。
